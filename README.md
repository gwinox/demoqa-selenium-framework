# DemoQA Selenium Framework

UI-автотесты для учебного сайта [demoqa.com](https://demoqa.com/) на собственном фреймворке поверх чистого Selenium WebDriver, без готовых обёрток. Работа с драйвером, ожидания, элементы, алерты, фреймы и вкладки реализованы с нуля.

## Стек

* Java 17, Maven
* Selenium WebDriver 4
* TestNG (в том числе DataProvider)
* Jackson
* Log4j2
* Lombok
* Datafaker
* Паттерн Page Object

## Что проверяют тесты

* `AlertsTest` — три вида алертов: простой алерт, подтверждение с проверкой результата и prompt со вводом случайного текста.
* `FramesTest` — тексты во вложенных фреймах (родительском и дочернем) и совпадение текстов в двух фреймах на странице Frames.
* `WebTablesTest` — параметризованный тест через DataProvider: для каждого пользователя из `data.json` добавляет запись в таблицу через модальное окно, проверяет её появление и удаляет.
* `BrowserWindowsTest` — открытие новой вкладки, закрытие и возврат на исходную, переход по ссылке в новую вкладку и переключение между вкладками.

## Архитектура проекта

Проект разделён на переиспользуемое ядро и реализацию для конкретного сайта.

1. `framework` — ядро, не привязанное к DemoQA:
   * `browser` — `Browser` (singleton WebDriver, клик через JavaScript, переключение и закрытие вкладок), `BrowserFactory` (создание Chrome или Firefox с аргументами и языком из конфига), `Wait` (обёртки над явными ожиданиями `WebDriverWait`).
   * `elements` — `BaseElement` и наследники `Button`, `Input`, `Text`: поиск с ожиданием, клик, ввод, получение текста, проверка видимости.
   * `page` — `BasePage`: проверка открытия страницы по уникальному элементу.
   * `test` — `BaseTest`: открытие сайта перед каждым тестом и закрытие браузера после.
   * `configuration` — чтение `config.json` в объект настроек через Jackson.
   * `utils` — работа с алертами и фреймами, логирование через Log4j2, генерация случайного текста.
2. `demoqa` — реализация для DemoQA:
   * `pages` — Page Object для разделов Elements и Alerts, Frame & Windows.
   * `model` — модели тестовых данных (`TestData`, `User`).
   * `manager` — `DataManager` для загрузки тестовых данных из `data.json`.
3. `tests` — тестовые сценарии.

## Конфигурация и данные

Все настройки и тестовые данные лежат в `src/test/resources`:

* `config.json` — базовый URL, таймауты, браузер (`chrome` или `firefox`), запуск в развёрнутом окне, язык и аргументы запуска браузера.
* `data.json` — ожидаемые тексты для проверок и пользователи для теста таблицы.
* `log4j2.xml` — логирование в консоль и в файл `target/logs/test.log`.

## Запуск тестов

Требуется JDK 17 или новее, Maven и установленный Chrome или Firefox. Драйвер браузера отдельно скачивать не нужно: Selenium Manager загрузит его автоматически.

**Через IDE (IntelliJ IDEA)**

1. Откройте папку проекта, в которой лежит `pom.xml`.
2. Дождитесь импорта Maven-зависимостей и индексации.
3. Откройте нужный класс в `src/test/java/tests` и нажмите кнопку Run рядом с названием класса или метода.

**Через терминал**

Перейдите в папку проекта, в которой лежит `pom.xml`, и выполните:

```bash
mvn clean test
```

Чтобы запустить тесты в другом браузере, поменяйте значение `browser` в `config.json`.
